# Smart Parking - Reconnaissance de Véhicules

Projet réalisé en 2022 dans le cadre de ma formation en Terminale STI2D. Ce projet de fin d'études, d'une durée de 3 mois, consistait à répondre à la problématique d'un "client" souhaitant automatiser la détection de véhicules sur des places de parking.

## Présentation du projet

L'objectif principal était de concevoir et d'entraîner une Intelligence Artificielle (IA) capable de différencier une place de parking occupée d'une place vide.
Points clés :

   - Développement "From Scratch" : Conception du modèle sans utiliser de bibliothèques de haut niveau pré-entraînées pour mieux comprendre la logique des réseaux de neurones.

   - Auto-formation : Apprentissage des concepts du Machine Learning et du Deep Learning via des ressources documentaires et tutoriels spécialisés.

## Données et Entraînement

Le modèle a été entraîné sur une base de données conséquente pour garantir une bonne précision.

   - Source des données : Datasets récupérés sur Kaggle.

   - Volume : Utilisation d'un dataset de 64 000 images de voitures (mélangées à des images "lambda" pour la classification binaire).

   - Technologie : Réseaux de neurones (CNN).
